# shipyard-cp v0.5.0

2026-07-12

`v0.5.0` は、production向け永続化を強化し、自己改善観測producerと低リスクのローカル推論routingを追加するminor releaseです。

## Highlights

- Redisを正本とするControl Plane repositoryを拡張し、再起動後の状態復旧と監査projection再構築を強化。
- `self-improvement/v1`向けのsanitized Observation export API/CLIとEvidence明示ackを追加。
- LM Studio / LM LinkのOpenAI互換APIを、低リスクの`plan` / `dev`へ限定して利用できるroutingを追加。
- worker verdict、人手override、Gate評価のoptional audit metadataを追加。

## Compatibility

- Task、WorkerJob、WorkerResult、Retrospective、Acceptanceの既存wire shapeを維持。
- 既存audit eventへの追加fieldはoptionalで、欠損値は`unknown`として扱う。
- 自己改善機能は既定non-blockingで、Gateやpolicyを自動変更しない。
- Redis key namespaceは`${REDIS_KEY_PREFIX}v2:`であり、旧memory状態・旧keyの自動移行は行わない。

## Non-scope

- Gate削除、policy緩和、Skill公開の自動化。
- `agent-gatefield` / `agent-state-gate`の判定コード変更。
- LM Studio側のモデルload/unloadやremote device管理。
